![TensorFlow](https://img.shields.io/badge/TensorFlow-FF6F00?style=flat&logo=tensorflow&logoColor=white)

![SQLite](https://img.shields.io/badge/SQLite-003B57?style=flat&logo=sqlite&logoColor=white)

A monitoring platform that detects anomalies in real-time system metrics and keeps working even when connectivity drops.

- 🧠 **LSTM Autoencoder** for anomaly detection on system metrics: full workflow from exploratory analysis and feature engineering to model evaluation
- 🔁 **Automated retraining pipeline** that re-evaluates the model on fresh data every 30 days to handle concept drift without manual intervention
- 📴 **Offline-first data pipeline**: SQLite buffering with JWT/HTTPS sync for reliable collection under intermittent connectivity
- 📊 **Dashboard** (Laravel, Chart.js) and **automated daily PDF reports** that turn model output into insights non-technical users can act on

### PreFail: Predictive Server Health Monitoring Platform *(Graduation Project, in progress)*

![Python](https://img.shields.io/badge/Python-3776AB?style=flat&logo=python&logoColor=white)
![FastAPI](https://img.shields.io/badge/FastAPI-009688?style=flat&logo=fastapi&logoColor=white)

![SQLite](https://img.shields.io/badge/SQLite-003B57?style=flat&logo=sqlite&logoColor=white)

Forecasts server failure risk **5 minutes ahead** and classifies the system state (Memory Leak, CPU Saturation, Disk Bottleneck, Network Congestion) using statistical signal detection across CPU, memory, disk, and network metrics.

- 🔐 Dual authentication: JWT for the admin dashboard, scoped API keys for monitoring agents
- 📴 Offline-first agents with local SQLite buffering and sync reconciliation
- 🔁 Human-in-the-loop corrections captured for future model retraining
- 📄 Automated PDF reports (fleet-wide and per-server)
